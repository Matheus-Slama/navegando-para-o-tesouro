# Imagens de interface

Use nomes em inglês, minúsculos e separados por hífens, no formato `tipo-funcao[-variante].ext`.

| Prefixo | Uso | Exemplo |
|---|---|---|
| `icon-` | Ícones de ações, navegação e informações | `icon-settings.png` |
| `button-` | Fundos de botões | `button-rectangle.png` |
| `panel-` | Fundos de painéis | `panel-hud.png` |
| `indicator-` | Indicadores com variantes de estado | `indicator-lives-3.png` |

Prefira a função na interface a descrições do tema visual, como `pirate` ou `wooden`. Preserve a extensão original. Ao renomear uma imagem, atualize os caminhos nos componentes, no CSS e na documentação, incluindo referências montadas dinamicamente.
